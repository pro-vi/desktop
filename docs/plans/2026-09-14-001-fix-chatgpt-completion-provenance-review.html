Only a final response may become success.

The controller decides whether a ChatGPT surface is final. HTTP then writes and receipts only that qualified output. Page reads bind returned text to a resolved tab and served URL.

3 implementation unitsreceipt v1 retainedlive DOM evidence unverified

Decision

Do not infer completion from length, duration, or a receipt hash. Use narrow provider-native terminal evidence before artifact creation. Reject conflicting read selectors and return served-page provenance.

Implementation units

U1
Qualify final controller output; transient thinking and planning stay non-final.
U2
Gate artifact, receipt, compatibility terminal, and run success on that qualification.
U3
Reject conflicting page selectors; return tab/key/served URL with MCP structured content.
